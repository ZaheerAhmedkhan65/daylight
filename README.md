# Daylight

A local-first task planner built with Flutter. Plan your day, browse upcoming
tasks, organize work into projects, and create tasks with priorities, reminders,
and subtasks. Tasks are saved on the device; no backend account is required.

## Getting Started

Install the Flutter SDK, fetch dependencies, then run:

```sh
flutter pub get
flutter run
```

Run the widget tests with:

```sh
flutter test
```
